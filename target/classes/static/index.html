Ataque Descripción Prevención
Fuerza bruta GraphQL batching El atacante agrupa múltiples intentos de inicio de sesión en una sola petición HTTP para burlar el rate limiting estándar y adivinar credenciales rápidamente Aplicar rate limiting y control de complejidad de consultas a nivel de operación individual dentro de los lotes, o deshabilitar batching
Modificación sin autenticación Un atacante con un token robado cambia el correo de la cuenta vía PUT /account sin verificar la contraseña actual, facilitando un posterior restablecimiento de acceso Solicitar obligatoriamente la contraseña actual del usuario antes de permitir modificaciones en datos sensibles
JWT vulnerable (alg: none) Manipulación de tokens aceptando algoritmos débiles o alg: none para alterar roles y escalar privilegios a administrador sin verificación criptográfica Verificar siempre la firma criptográfica, rechazar explícitamente algoritmos inseguros o alg: none, y comprobar fechas de caducidad
